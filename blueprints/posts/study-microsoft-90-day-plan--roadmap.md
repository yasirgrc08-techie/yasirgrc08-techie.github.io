# Prepare for Microsoft in 90 Days / Learning Roadmap

By Yasir Sharfi

## The Idea

Is 90 days enough?

Prepare around the actual role: problem solving, design, coding, testing, and relevant technical depth. A storage role, product backend role, and ML platform role need different specialization. Use the job description and recruiter guidance to select that depth.

## Visual Blueprint

1. **Build the mental model**: Attempt one medium coding problem without notes, explain a previous project for ten minutes, and design a small API.
2. **Phase 1 / Weeks 1-3**: Practice arrays, hashing, two pointers, sliding windows, stacks, and binary search.
3. **Phase 2 / Weeks 4-6**: Add trees, graph traversal, heaps, intervals, and introductory dynamic programming.
4. **Phase 3 / Weeks 7-9**: Work through a cache, notification service, file service, or other role-relevant system.
5. **Phase 4 / Weeks 10-12**: Alternate unseen coding mocks, project deep dives, and design discussions. Review the actual job requirements and current recruiter instructions.
6. **Prove readiness**: Recent unseen coding mocks show independent correctness and clear tests.
