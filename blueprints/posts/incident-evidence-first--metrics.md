# Incidents Need an Evidence Trail / Metrics That Matter

By Yasir Sharfi

## The Idea

Changing five things at once can restore service and erase the explanation.

During an incident, prioritize user impact and controlled mitigation while preserving enough evidence to distinguish causes and verify recovery.

## Visual Blueprint

1. **Time to useful diagnosis**: Measure when the team identified a testable controlling boundary.
2. **Interpret / Time to useful diagnosis**: The first plausible story is not necessarily the first supported diagnosis.
3. **Mitigation effectiveness**: Compare user impact before and after each major action.
4. **Interpret / Mitigation effectiveness**: Several simultaneous actions make it harder to know which one helped.
5. **Recurrence prevention**: Track completion and verification of concrete follow-up actions.
6. **Interpret / Recurrence prevention**: A long postmortem document is not evidence that the failure mode was addressed.
