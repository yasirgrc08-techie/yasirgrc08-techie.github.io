# A Complete 12-Week SWE Study Plan / Readiness Signals

By Yasir Sharfi

## The Idea

Should all subjects receive equal time?

Connect topics through one small service instead of completing unrelated courses. Algorithms teach efficient computation; OS and networks explain execution; databases preserve state; design coordinates the pieces. The project makes gaps visible while mocks test whether the learning transfers.

## Visual Blueprint

1. **Explain**: Foundational problems can be solved without a template.
2. **Interpret / Explain**: Can a new reader reproduce the service without private configuration?
3. **Implement**: One end-to-end request and failure path can be explained.
4. **Interpret / Implement**: Do malformed input, duplicate creation, and worker restart have explicit tests?
5. **Verify**: The project has reproducible setup and meaningful tests.
6. **Interpret / Verify**: Are secrets excluded and all sample data synthetic?
