# Python Foundations for Data and AI Work / Learning Roadmap

By Yasir Sharfi

## The Idea

Is vectorized code always faster?

Good AI work depends on ordinary software discipline: clear functions, validated inputs, tests, dependency management, and reproducible data transformations. Learn Python and numerical tools through small tasks whose expected result you can compute independently.

## Visual Blueprint

1. **Build the mental model**: Use functions and modules for reusable logic, with explicit inputs and outputs.
2. **Phase 1 / Week 1**: Practice functions, lists, dictionaries, sets, iteration, exceptions, pathlib, and tests. Write a small command-line data validator.
3. **Phase 2 / Week 2**: Read CSV and JSON with standard parsers, normalize types deliberately, and handle duplicates and missing values.
4. **Phase 3 / Week 3**: Practice vector shapes, matrix multiplication, reductions, broadcasting, and random seeds. Compare a vectorized calculation with a simple loop on small data.
5. **Phase 4 / Week 4**: Create an isolated environment, record dependency versions, split data before fitted preprocessing, and save experiment configuration.
6. **Prove readiness**: Functions and data contracts are explicit and tested.
