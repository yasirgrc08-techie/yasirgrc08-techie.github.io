# A Non-CS Graduate's Software Roadmap / Practice Decisions

By Yasir Sharfi

## The Idea

Which language should I learn first?

Learn programming, data structures, systems basics, and one complete project in dependency order. The goal is to make software behavior understandable and testable, not to collect certificates or assume that a degree label determines your engineering ability.

## Visual Blueprint

1. **Start with programs you can trace**: Choose one language and learn variables, functions, collections, loops, errors, and basic I/O. Predict the result before running each exercise.
2. **Watch for**: Skipping basic programming to begin advanced AI or distributed-system courses.
3. **Connect theory to behavior**: Implement a queue, inspect a network request, and store records in a database. These small demonstrations make formal terms concrete.
4. **Watch for**: Treating certificates as substitutes for inspectable code and tests.
5. **Use your existing domain carefully**: An electronics background can motivate a telemetry or device simulator project. Use synthetic data and ordinary public protocols.
6. **Watch for**: Overstating a small educational project as production-scale experience.
