# Prepare for Microsoft in 90 Days / Practice Decisions

By Yasir Sharfi

## The Idea

Is 90 days enough?

Prepare around the actual role: problem solving, design, coding, testing, and relevant technical depth. A storage role, product backend role, and ML platform role need different specialization. Use the job description and recruiter guidance to select that depth.

## Visual Blueprint

1. **Start from a diagnostic**: Attempt one medium coding problem without notes, explain a previous project for ten minutes, and design a small API.
2. **Watch for**: Collecting solved counts while avoiding timed unseen problems and boundary tests.
3. **Use official scope, not question predictions**: Microsoft's technical guidance emphasizes problem solving, design, coding, and testing, with role-dependent areas such as distributed systems, networking, and AI/ML.
4. **Watch for**: Treating every Microsoft team as if it had the same interview and specialization.
5. **Keep preparation sustainable**: Reserve short weekday sessions and one longer weekend mock. Keep one implementation language throughout the plan.
6. **Watch for**: Using confidential workplace code, data, or incidents in a public preparation project.
