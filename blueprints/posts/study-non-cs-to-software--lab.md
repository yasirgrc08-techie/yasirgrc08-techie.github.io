# A Non-CS Graduate's Software Roadmap / Build and Validate

By Yasir Sharfi

## The Idea

Which language should I learn first?

Learn programming, data structures, systems basics, and one complete project in dependency order. The goal is to make software behavior understandable and testable, not to collect certificates or assume that a degree label determines your engineering ability.

## Visual Blueprint

1. **Set up the scenario**: A simulator produces a device ID, timestamp, and temperature. Store readings and return the latest value per device.
2. **Experiment 1**: Define units, timestamp format, valid ranges, and what happens when a reading arrives late.
3. **Experiment 2**: Implement input validation and persistence.
4. **Experiment 3**: Test empty history, duplicate readings, invalid units, and out-of-order arrival.
5. **Expected evidence**: The project connects programming, data structures, networking, and database reasoning.
6. **Check the result**: Can you write the core logic without copying the tutorial?
