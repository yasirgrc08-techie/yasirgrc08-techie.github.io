# Prepare for Microsoft in 90 Days / Build and Validate

By Yasir Sharfi

## The Idea

Is 90 days enough?

Prepare around the actual role: problem solving, design, coding, testing, and relevant technical depth. A storage role, product backend role, and ML platform role need different specialization. Use the job description and recruiter guidance to select that depth.

## Visual Blueprint

1. **Set up the scenario**: You recognize a sliding-window problem, but your implementation returns the wrong result when characters repeat near the left boundary.
2. **Experiment 1**: Write the exact failing input and explain which invariant broke.
3. **Experiment 2**: Implement the correction from a blank editor. Trace repeated characters, an empty input if allowed, and a one-character input.
4. **Experiment 3**: On days two and four, solve related but different window problems.
5. **Expected evidence**: A documented failure, a minimal correction, two transfer exercises, and a new mock score provide evidence of learning.
6. **Check the result**: Can you state the invariant before typing code?
