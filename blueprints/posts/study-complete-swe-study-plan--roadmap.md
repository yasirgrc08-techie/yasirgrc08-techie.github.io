# A Complete 12-Week SWE Study Plan / Learning Roadmap

By Yasir Sharfi

## The Idea

Should all subjects receive equal time?

Connect topics through one small service instead of completing unrelated courses. Algorithms teach efficient computation; OS and networks explain execution; databases preserve state; design coordinates the pieces. The project makes gaps visible while mocks test whether the learning transfers.

## Visual Blueprint

1. **Build the mental model**: Use a language you can debug and test, plus one web framework and one database. Learn the standard library before collecting frameworks.
2. **Phase 1 / Weeks 1-3**: Review language syntax, testing, arrays, maps, pointers or references, stacks, and binary search. Start an API skeleton with one endpoint and a local database.
3. **Phase 2 / Weeks 4-6**: Study processes, threads, virtual memory, DNS, TCP, HTTP, SQL joins, indexes, and transactions.
4. **Phase 3 / Weeks 7-9**: Practice recursion, dynamic programming, caching, retries, idempotency, and queues.
5. **Phase 4 / Weeks 10-12**: Run timed unseen coding problems and project walkthroughs. Practice concise behavioral stories and revise the weakest mock dimensions.
6. **Prove readiness**: Foundational problems can be solved without a template.
