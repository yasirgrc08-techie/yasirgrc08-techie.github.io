# A Complete 12-Week SWE Study Plan / Practice Decisions

By Yasir Sharfi

## The Idea

Should all subjects receive equal time?

Connect topics through one small service instead of completing unrelated courses. Algorithms teach efficient computation; OS and networks explain execution; databases preserve state; design coordinates the pieces. The project makes gaps visible while mocks test whether the learning transfers.

## Visual Blueprint

1. **Choose one implementation stack**: Use a language you can debug and test, plus one web framework and one database. Learn the standard library before collecting frameworks.
2. **Watch for**: Switching languages and frameworks whenever progress slows.
3. **Study dependencies in order**: Arrays and functions precede complex algorithms; processes and sockets make concurrency and web behavior easier to understand.
4. **Watch for**: Reading solutions without implementing or testing them independently.
5. **Create a weekly evidence bundle**: Save a solved unseen problem, a test result, a small project improvement, and a short explanation of one concept.
6. **Watch for**: Presenting a tutorial clone as original production experience.
