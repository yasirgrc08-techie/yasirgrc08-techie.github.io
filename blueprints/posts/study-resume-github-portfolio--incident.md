# Build a Resume and GitHub Portfolio / Pitfalls and Checks

By Yasir Sharfi

## The Idea

Should I include every technology I have tried?

A useful portfolio answers three questions: what problem did you solve, what did you personally build, and how can someone verify it? Align the resume, repository, demo, and interview narrative so a reviewer sees one consistent, defensible story.

## Visual Blueprint

1. **Trap 1**: Publishing secrets or assuming deletion removes them from history.
2. **Counter-check 1**: All links and setup instructions have been checked.
3. **Trap 2**: Calling a local demo highly scalable without a workload or evidence.
4. **Counter-check 2**: Each project has a clear scope and at least one meaningful test.
5. **Trap 3**: Using generic AI-generated claims that do not match the repository.
6. **Counter-check 3**: Resume metrics and ownership claims are supportable.
