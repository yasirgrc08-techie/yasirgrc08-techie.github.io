# A Non-CS Graduate's Software Roadmap / Readiness Signals

By Yasir Sharfi

## The Idea

Which language should I learn first?

Learn programming, data structures, systems basics, and one complete project in dependency order. The goal is to make software behavior understandable and testable, not to collect certificates or assume that a degree label determines your engineering ability.

## Visual Blueprint

1. **Explain**: Small programs can be implemented and debugged independently.
2. **Interpret / Explain**: Can you write the core logic without copying the tutorial?
3. **Implement**: Core data structures can be compared using concrete operations.
4. **Interpret / Implement**: Does a peer reproduce the service from the README?
5. **Verify**: One project has clear setup, contracts, and tests.
6. **Interpret / Verify**: Do out-of-order and duplicate events follow the documented rule?
