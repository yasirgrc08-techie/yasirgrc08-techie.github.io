# AI and ML Foundations in Six Weeks / Pitfalls and Checks

By Yasir Sharfi

## The Idea

When should I avoid ML?

Learn ML as a decision-making pipeline rather than a catalogue of model names. Define the prediction time, label, objective, data split, baseline, and error costs before optimizing a model. Reliable evaluation and data quality usually matter more than an impressive architecture diagram.

## Visual Blueprint

1. **Trap 1**: Choosing a model before defining the prediction and action.
2. **Counter-check 1**: Prediction time, labels, and available features are explicit.
3. **Trap 2**: Including future information in features or preprocessing.
4. **Counter-check 2**: A simple baseline is evaluated fairly.
5. **Trap 3**: Reporting one aggregate metric without a baseline or error analysis.
6. **Counter-check 3**: Metrics and thresholds match error costs and constraints.
