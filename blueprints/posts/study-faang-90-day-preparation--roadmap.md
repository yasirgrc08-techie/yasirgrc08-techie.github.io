# FAANG Preparation Without Question Chasing / Learning Roadmap

By Yasir Sharfi

## The Idea

How many problems should I solve?

Build transferable coding, design, and communication skills, then tailor the final revision to the actual team and level. Use official hiring guidance for scope, mocks for diagnosis, and a limited resource set for consistent practice. Avoid treating alleged question frequency as a hiring guarantee.

## Visual Blueprint

1. **Build the mental model**: Coding fundamentals are reusable, but design depth, specialization, and behavioral expectations vary with level and team.
2. **Phase 1 / Days 1-21**: Run coding and project diagnostics. Review arrays, hashing, pointers, windows, stacks, and search.
3. **Phase 2 / Days 22-45**: Add trees, graphs, heaps, intervals, backtracking, and DP. Mix patterns and compare multiple approaches.
4. **Phase 3 / Days 46-70**: Practice role-relevant architecture, capacity estimates, data contracts, retries, and recovery.
5. **Phase 4 / Days 71-90**: Confirm interview structure and tools. Run mocks that resemble the expected rounds, then correct one measurable weakness per session.
6. **Prove readiness**: Mixed coding mocks are independently correct and tested.
