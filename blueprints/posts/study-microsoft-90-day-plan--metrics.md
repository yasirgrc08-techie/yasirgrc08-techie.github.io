# Prepare for Microsoft in 90 Days / Readiness Signals

By Yasir Sharfi

## The Idea

Is 90 days enough?

Prepare around the actual role: problem solving, design, coding, testing, and relevant technical depth. A storage role, product backend role, and ML platform role need different specialization. Use the job description and recruiter guidance to select that depth.

## Visual Blueprint

1. **Explain**: Recent unseen coding mocks show independent correctness and clear tests.
2. **Interpret / Explain**: Can you state the invariant before typing code?
3. **Implement**: One role-relevant design includes recovery, trade-offs, and capacity assumptions.
4. **Interpret / Implement**: Does the boundary case fail on the original implementation and pass after the correction?
5. **Verify**: Project and behavioral examples distinguish your actions from the team's work.
6. **Interpret / Verify**: Can you apply the idea to an unseen variation without reading a template?
