# A Non-CS Graduate's Software Roadmap / Learning Roadmap

By Yasir Sharfi

## The Idea

Which language should I learn first?

Learn programming, data structures, systems basics, and one complete project in dependency order. The goal is to make software behavior understandable and testable, not to collect certificates or assume that a degree label determines your engineering ability.

## Visual Blueprint

1. **Build the mental model**: Choose one language and learn variables, functions, collections, loops, errors, and basic I/O. Predict the result before running each exercise.
2. **Phase 1 / Weeks 1-4**: Study one language, command-line basics, Git, functions, collections, file handling, and tests.
3. **Phase 2 / Weeks 5-8**: Practice arrays, maps, stacks, queues, search, sorting, and elementary recursion. Learn processes, memory, HTTP, and relational tables at an introductory level.
4. **Phase 3 / Weeks 9-12**: Build a task tracker, telemetry dashboard, or inventory service. Define a minimal contract, persist records, validate input, and write automated tests.
5. **Phase 4 / Weeks 13-16**: Practice mixed coding, project explanation, and basic design. Read actual junior-role descriptions and close their specific gaps.
6. **Prove readiness**: Small programs can be implemented and debugged independently.
