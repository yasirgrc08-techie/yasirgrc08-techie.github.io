# A Complete 12-Week SWE Study Plan / Pitfalls and Checks

By Yasir Sharfi

## The Idea

Should all subjects receive equal time?

Connect topics through one small service instead of completing unrelated courses. Algorithms teach efficient computation; OS and networks explain execution; databases preserve state; design coordinates the pieces. The project makes gaps visible while mocks test whether the learning transfers.

## Visual Blueprint

1. **Trap 1**: Switching languages and frameworks whenever progress slows.
2. **Counter-check 1**: Foundational problems can be solved without a template.
3. **Trap 2**: Reading solutions without implementing or testing them independently.
4. **Counter-check 2**: One end-to-end request and failure path can be explained.
5. **Trap 3**: Presenting a tutorial clone as original production experience.
6. **Counter-check 3**: The project has reproducible setup and meaningful tests.
