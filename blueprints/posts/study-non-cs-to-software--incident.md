# A Non-CS Graduate's Software Roadmap / Pitfalls and Checks

By Yasir Sharfi

## The Idea

Which language should I learn first?

Learn programming, data structures, systems basics, and one complete project in dependency order. The goal is to make software behavior understandable and testable, not to collect certificates or assume that a degree label determines your engineering ability.

## Visual Blueprint

1. **Trap 1**: Skipping basic programming to begin advanced AI or distributed-system courses.
2. **Counter-check 1**: Small programs can be implemented and debugged independently.
3. **Trap 2**: Treating certificates as substitutes for inspectable code and tests.
4. **Counter-check 2**: Core data structures can be compared using concrete operations.
5. **Trap 3**: Overstating a small educational project as production-scale experience.
6. **Counter-check 3**: One project has clear setup, contracts, and tests.
