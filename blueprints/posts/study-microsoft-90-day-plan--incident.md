# Prepare for Microsoft in 90 Days / Pitfalls and Checks

By Yasir Sharfi

## The Idea

Is 90 days enough?

Prepare around the actual role: problem solving, design, coding, testing, and relevant technical depth. A storage role, product backend role, and ML platform role need different specialization. Use the job description and recruiter guidance to select that depth.

## Visual Blueprint

1. **Trap 1**: Collecting solved counts while avoiding timed unseen problems and boundary tests.
2. **Counter-check 1**: Recent unseen coding mocks show independent correctness and clear tests.
3. **Trap 2**: Treating every Microsoft team as if it had the same interview and specialization.
4. **Counter-check 2**: One role-relevant design includes recovery, trade-offs, and capacity assumptions.
5. **Trap 3**: Using confidential workplace code, data, or incidents in a public preparation project.
6. **Counter-check 3**: Project and behavioral examples distinguish your actions from the team's work.
